# DeepSeek Harness Desktop v2.0.3

Official Linux release of DSH Desktop for Ubuntu 24.04+, Debian, and universal Linux distributions.

### ✨ What's New & Highlights

- **🐧 Native Linux Desktop Port**: Fully tested on Ubuntu 24.04 LTS (x86_64).
- **📦 Debian Package & Portable AppImage**: Native `.deb` and standalone `.AppImage` distribution targets.
- **⚡ Hotkeys**: Standard shortcuts for Reload (`Ctrl+R` / `F5`), Force Reload (`Ctrl+Shift+R`), DevTools (`Ctrl+Shift+I` / `F12`), and Zoom (`Ctrl+=` / `Ctrl+-`).

---

### 📥 Installation Instructions

#### Ubuntu / Debian (.deb)
```bash
wget https://github.com/nicolodon/dsh-linux/releases/download/v2.0.3/dsh-linux_2.0.3_amd64.deb
sudo apt install ./dsh-linux_2.0.3_amd64.deb
```

#### Universal Linux (.AppImage)
```bash
wget https://github.com/nicolodon/dsh-linux/releases/download/v2.0.3/dsh-linux-2.0.3-x86_64.AppImage
chmod +x dsh-linux-2.0.3-x86_64.AppImage
./dsh-linux-2.0.3-x86_64.AppImage
```

#### Canonical Snap Store
```bash
sudo snap install dsh-linux
```
